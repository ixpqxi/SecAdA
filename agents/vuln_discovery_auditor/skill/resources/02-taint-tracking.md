# 污点分析与路径追踪指南

## 1. 污点分析三要素
- **Source（广义）**：不仅是 GET/POST。注意定时任务读取、第三方 API 回调、数据库二次读取等高阶污染源。
- **Sanitizer（消毒器绕过）**：
  - 上下文错位：用防 SQL 注入的函数去过滤进入 `eval()` 的数据。
  - 编码不一致：底层组件对宽字节（GBK）、二次 URL 编码解析不同导致的隐身。
- **Sink（执行点）**：`system()`, `PDO query()`, `__destruct()` 等。

## 2. 路径断裂特性预警
- **PHP**：注意动态变量 `$a($b)`、反射类 `ReflectionMethod`、魔术方法触发导致的数据流静态断裂。
- **Java**：注意 Spring 依赖注入（`@Autowired`）、AOP 切面修改参数、动态代理导致的调用图（CG）断裂。
